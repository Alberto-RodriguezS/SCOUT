# Avance 4 | Alignment Checkpoint

Following our most recent advisory session with Dr. Carlos Villaseñor, the team prioritized aligning the project's technical direction and expected deliverables with the requirements of our MIT sponsor, Dr. Camilo Mora, before proceeding with additional model development.

This checkpoint documents the work completed during the current period, including conceptual diagrams and preliminary interface mockups prepared to support that alignment process.

The materials have been shared with Dr. Mora, and his feedback is currently pending.

Consequently, this submission represents an intermediate project checkpoint rather than the completed alternative-model comparison required by the original assignment. Model development and evaluation will be revisited once the necessary alignment has been established.
